# XSG — 概要

## これは何か

XSG は、ディスプレイの検査・調整に使うテストパターンを表示するアプリケーションです。
ブラウザ上でも、インストールしたデスクトップアプリとしても動作します。

## なぜ作ったか

ディスプレイをきちんと調整しようとすると、業務用の信号発生器が必要になります。
ところがそういった機器は数十万円以上することが珍しくなく、個人や小規模な現場では手が届きません。

「ちゃんとモニターを合わせたい」「放送機器のテストをしたい」「色が正確かどうか確かめたい」——
そんな当たり前の欲求を、無料のソフトウェアで叶えたい。それが XSG の出発点です。

## 届けたい体験

- 起動したら即座にテストパターンが全画面に広がっている
- 必要なパターンを迷わず選べる
- OS のガンマやナイトモードに邪魔されず、正確な状態で作業できる
- 複数のモニターを同時に扱える
- 高価な機材がなくても、プロと同じ水準の確認ができる

## 対象とする人

- 映像技術者・放送機器エンジニア
- モニターの品質確認をしたい開発者・デザイナー
- 業務用信号発生器の代替を探しているすべての人

## 前バージョン（pg）からの進化

XSG は、以前から使ってきた映像テストツール「pg」を全面的に作り直したものです。
pg の全機能を引き継ぎつつ、パターン定義の仕組みを整理し、マルチディスプレイ対応や
キャリブレーション支援など、新しい機能を加えています。
pg 用のパターン定義ファイルを XSG 形式に変換するツールも付属しています。
