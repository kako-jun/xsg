# XSG — 機能一覧

## テストパターン

25 種類以上のパターンを即座に切り替えて表示できます。

### カラーバー

| パターン         | 概要                               |
| ---------------- | ---------------------------------- |
| SMPTE カラーバー | 放送業界標準の 75% カラーバー      |
| EBU カラーバー   | ヨーロッパ放送連合規格のカラーバー |
| ARIB カラーバー  | 日本の ARIB 規格準拠のカラーバー   |

### グレースケール・グラデーション

| パターン         | 概要                                                 |
| ---------------- | ---------------------------------------------------- |
| グレースケール   | 16 段階のグレースケール帯                            |
| ステアケース     | 0〜100% を 5% 刻みで表示する 21 段階階調             |
| 縦グラデーション | 滑らかな縦方向グラデーション（ステップ数を変更可能） |
| 横グラデーション | 滑らかな横方向グラデーション（ステップ数を変更可能） |

### 単色フィールド

白・黒・赤・緑・青・シアン・マゼンタ・黄の 8 色。
任意の色コードで指定することも可能です。

### 幾何学パターン

| パターン         | 概要                                           |
| ---------------- | ---------------------------------------------- |
| チェッカーボード | 白黒の市松模様                                 |
| クロスハッチ     | グリッド状の格子パターン（1px・2px の 2 種類） |
| コンバージェンス | 中央に十字線付きのアライメントグリッド         |

### プロフェッショナル向けパターン

| パターン                     | 概要                                             |
| ---------------------------- | ------------------------------------------------ |
| PLUGE                        | 黒レベルの調整に使う                             |
| マルチバースト               | 周波数応答テスト用                               |
| ピクセル欠陥シミュレーション | 死亡ピクセル・輝点を模擬して表示（XSG 独自機能） |

ピクセル欠陥シミュレーションは、既製の業務用信号発生器にもない XSG 独自の機能です。
品質保証・工場検査などで活用できます。

## フルスクリーン・フレームレス表示

デスクトップアプリとして起動すると、タイトルバーも境界線もない完全なフルスクリーン表示になります。
パターンが画面全体を占有するため、正確なキャリブレーション作業が可能です。

## マルチディスプレイ対応

複数モニターが接続された環境で、表示先を柔軟に指定できます。

- 全ディスプレイに同時表示
- プライマリディスプレイのみ
- 位置（左端・右端・上端・下端・左から N 番目など）で指定
- カンマ区切りで複数のディスプレイを同時指定

## ディスプレイキャリブレーション支援

正確なテストを阻害する OS の設定を検出・制御します。

| 設定                                      | できること                                     |
| ----------------------------------------- | ---------------------------------------------- |
| ガンマ補正                                | 現在値の表示・1.0 へのリセット・元の値への復元 |
| ナイトモード（Night Shift / Redshift 等） | 有効・無効の確認と無効化                       |
| HDR（Windows）                            | 有効・無効の確認                               |
| GPU 情報                                  | 検出して表示                                   |

変更前の値は自動的に保存され、後から元に戻せます。

## プレイリスト機能

複数のパターンを順番に自動再生します。

- 各パターンの表示時間を秒単位で設定
- ループ再生・ランダム順再生
- パターンファイルの参照・インライン定義・画像 URL の混在が可能

## カスタムパターン

テキストファイルを編集するだけで、オリジナルのパターンを定義できます。
既存パターンを継承してパラメータだけ変えることも可能です。

## Web レンダリングモード

任意の URL をフルスクリーン・フレームレスで表示するモードです。
テストパターン用途を超えた使い方ができます。

- Web キオスク端末
- デジタルサイネージ
- ダッシュボードの大型モニター表示

読み取り専用モードを有効にすると、表示したページへの操作が無効になります。

## シングルインスタンス制御

XSG は同時に 1 つだけ起動します。
二重起動しようとすると、新しいプロセスは起動せず、すでに開いているウィンドウのパターンだけが切り替わります。
スクリプトからパターンを繰り返し変更しても、フルスクリーンウィンドウが増殖しません。
