# XSG — ロードマップ

## v1.0 リリースに向けて

現在の最優先事項は「動くものを世に出す」こと。
まずは基本的な使い方ができる状態で公開することを目指しています。

- すべてのテストパターンの動作確認
- スクリーンセーバーとしての動作確認（特に Windows の `.scr` 形式）
- README とスクリーンショットの整備
- Reddit（r/rust 等）での告知

## v1.1 の展望

### アニメーション対応

点滅したり移動したりするオブジェクトを表示できるようにしたい。
バックライトのちらつき確認や、動体解像度のテストに使えます。

### macOS のガンマ補正・Night Shift 対応

現時点では macOS のガンマ制御は未実装です。
macOS ユーザーにも完全な体験を届けるために対応します。

### カスタムパターンエディタ

テキストファイルを直接編集しなくても、GUI 上でパターンを視覚的に作成できる画面を用意したい。
プログラミングの知識がなくてもパターンを作れる状態を目指します。

## v1.2 の展望

### Rust による描画エンジンの刷新

パターン描画をより高精度・高速にするため、Rust への移行を検討しています。
将来のパターン収集・追加を見越して、基盤を強化する意図です。

### 著名なテストパターンの収集

放送・映像の世界には、長い歴史の中で使われてきた多様なテストパターンがあります。
Zone Plate・Needle など、より高度なパターンも順次追加していきたい。
懐かしいレトロなパターン（かつてのテレビ放送で使われた調整用画面など）も集めたいと考えています。

### ガンマ・輝度フィルターの拡充

OS のガンマだけでなく、グラフィックボード側のフィルター設定も洗い出して表示できるようにしたい。
「今どんな補正がかかっているか」を一目で把握できる画面を目指しています。

## 長期的な夢

### キャリブレーションウィザード

「ディスプレイを正しく調整したい」という初めての人でも迷わないよう、
ステップバイステップで案内するウィザードを作りたい。
パターンを表示しながら「次はここを調整してください」と説明する流れです。

### プラグインシステム

サードパーティが独自のパターンを追加できる仕組みを整えたい。
コミュニティが育てば、XSG はテストパターンの集積地になれる可能性があります。

### スケジュール機能・リモート管理

デジタルサイネージ用途での活用を広げるため、
時間帯によって表示内容を切り替えるスケジュール機能や、
複数台のモニターをまとめて管理するリモート制御を検討しています。
