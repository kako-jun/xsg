# XSG — 対応環境

## デスクトップアプリ

| OS                                  | 対応状況                   |
| ----------------------------------- | -------------------------- |
| Windows 10 / 11                     | 対応                       |
| Linux（主要ディストリビューション） | 対応                       |
| macOS                               | 対応（一部機能に制限あり） |

## Web ブラウザ版

ブラウザでアクセスするだけで使えるバージョンもあります。
インストール不要で、手軽にテストパターンを確認したい場面に向いています。

対応ブラウザ: Chrome / Firefox / Safari / Edge の最新版

ただし、デスクトップアプリ版と比べて以下の機能が制限されます：

- OS レベルのガンマ補正を制御できない
- フレームレス・フルスクリーンの制御がブラウザの仕様に依存する
- マルチディスプレイの自動検出・個別指定ができない

## 解像度

ウィンドウサイズに合わせてパターンを再描画するため、どの解像度でもシャープに表示されます。

- FHD（1920×1080）
- QHD（2560×1440）
- 4K（3840×2160）

## 制約事項

### ガンマ・ナイトモード制御の制限

| OS      | ガンマ制御   | ナイトモード制御                |
| ------- | ------------ | ------------------------------- |
| Windows | 対応         | 手動案内のみ（OS の制限による） |
| Linux   | 対応         | 対応（Redshift / f.lux を終了） |
| macOS   | 将来対応予定 | 将来対応予定                    |

Windows のナイトモード（夜間モード）は OS 側の制限により、XSG から直接無効化できません。
設定方法の案内は表示されます。

macOS のガンマ補正・Night Shift の制御は現時点では実装されておらず、将来のバージョンで対応予定です。

### シングルインスタンス制限

XSG は同時に 1 インスタンスのみ起動できます。
マルチディスプレイ機能で複数の画面に表示することはできますが、
異なるパターンを別々のウィンドウで同時表示することはできません。

### スクリーンセーバーの配布形式

| OS      | 形式                                 |
| ------- | ------------------------------------ |
| Windows | `.scr` ファイル（`System32` に配置） |
| Linux   | サービスとして動作                   |
| macOS   | `.app` バンドルとして動作            |
