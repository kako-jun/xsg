# XSG — 使い方

## 起動する

デスクトップアプリとして起動すると、即座にフルスクリーンでテストパターンが表示されます。
通常の使用時に UI は一切表示されません。画面全体がテストパターンです。

## パターンを選ぶ

**キーボードの `M` キー**を押すと、パターンメニューが開きます。
タッチデバイスでは画面右下のボタンをタップします。

メニューにはすべてのパターンがカテゴリ別に表示されています。
クリックすると即座に切り替わります。
閉じるには `ESC` キーを押すか、もう一度 `M` キーを押します。

## キャリブレーションパネルを使う

**`C` キー**を押すとキャリブレーションパネルが開きます。

表示される情報：

- 現在のガンマ値
- ナイトモードの有効・無効
- HDR の有効・無効（Windows）
- 接続中の GPU

操作できること：

- ガンマを 1.0 にリセット
- ガンマを元の値に戻す
- ナイトモードを無効化

## コマンドラインから起動する

GUI を使わず、コマンドラインから初期パターンや表示先ディスプレイを指定して起動できます。

### 主なオプション

| オプション        | 内容                                       |
| ----------------- | ------------------------------------------ |
| `--pattern`       | 初期表示パターンの指定                     |
| `--display`       | 表示先ディスプレイの指定                   |
| `--list-displays` | 接続中ディスプレイの一覧を表示して終了     |
| `--url`           | Web レンダリングモードで表示する URL       |
| `--readonly`      | Web レンダリング時にページへの操作を無効化 |
| `--playlist`      | プレイリストファイルを指定して自動再生     |

### 使用例

```
# SMPTEカラーバーで起動
xsg --pattern colorbar

# 左端のモニターにチェッカーボードを表示
xsg --pattern checker --display left

# 接続中のモニター一覧を確認
xsg --list-displays

# Webページをフルスクリーンで表示（操作不可）
xsg --url https://example.com --readonly

# プレイリストを再生
xsg --playlist inspection.yaml
```

## ディスプレイを指定する

`--list-displays` を実行すると、接続中のモニターの解像度・座標・位置グループが確認できます。

### 指定方法

```
--display all          全ディスプレイ（デフォルト）
--display primary      プライマリディスプレイのみ
--display left         左端のモニター
--display left-2       左から 2 番目のモニター
--display right        右端のモニター
--display top          上端のモニター
--display bottom       下端のモニター
--display left,right   左端と右端を同時に指定
```

## プレイリストを作る

複数のパターンを自動で切り替えたい場合は、テキストファイルでプレイリストを定義します。

```yaml
playlist:
  mode: sequence # sequence / random / shuffle
  loop: true
  defaultDuration: 5000 # 各パターンの表示時間（ミリ秒）

items:
  - pattern: colorbar
    duration: 3000
  - pattern: checker
    duration: 5000
  - pattern: grayscale
```

再生順序（`mode`）は次の3種類です。

- **sequence** … 定義した順に再生します。`loop: false` なら全件を再生したあと停止します。
- **shuffle** … 最初に一度だけシャッフルし、その順で再生します。`loop: false` なら全件を再生したあと停止します。
- **random** … 毎回ランダムに1つ選んで再生します。**`random` は終わりの概念が無いため、`loop` の設定に関わらず延々と再生し続けます**（`loop: false` にしても止まりません）。途中で止めたい場合は `sequence` か `shuffle` を使ってください。

スクリーンセーバーとして動作させる場合も、プレイリストを使って好きなパターンの組み合わせを設定できます。
